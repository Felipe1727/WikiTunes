# Propuesta: documentacion

## Por qué

El README se fue ampliando spec a spec y todavía decía «Proyecto en construcción». Con todas las funcionalidades listas, hace falta un README completo en español que permita instalar, levantar, usar y entender el proyecto sin leer el código.

## Qué cambia

- **README reescrito:**
  - presentación con una muestra real de la salida;
  - requisitos e inicio rápido;
  - uso: consultas, fichas, navegación y casos para probar;
  - base de datos, carga de datos, configuración, modelo de datos (diagrama ER y procedimientos);
  - procedencia de los datos, arquitectura, decisiones principales, y pruebas y lint.
- **Cada comando del README se ejecutó y funciona tal como está escrito.**
